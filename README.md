# MAVEN
MAVEN (Mars Atmosphere and Volatile EvolutioN) is NASA's Mars orbiter dedicated to studying the Martian upper atmosphere, ionosphere, and interactions with the solar wind. Its observations help explain how Mars lost much of its atmosphere over billions of years and provide insight into the planet's climate evolution and habitability.

This repository contains scripts and tools for analyzing data from NASA's MAVEN mission, which investigates the Martian upper atmosphere, ionosphere, and solar wind interactions. The project supports scientific analysis of spacecraft observations to better understand Mars atmosphere
